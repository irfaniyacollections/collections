COLLECTIONS – ഡാറ്റ Backup

ഈ പേജ് നിങ്ങളുടെ Firestore-ലെ collections_data / main രേഖ വായിച്ച് JSON ഫയലായി നിങ്ങളുടെ ഫോണിലേക്കോ കമ്പ്യൂട്ടറിലേക്കോ ഡൗൺലോഡ് ചെയ്യും. ഇത് ഡാറ്റയിൽ മാറ്റം വരുത്തുകയോ Delete ചെയ്യുകയോ ഇല്ല.

സുരക്ഷാ മുന്നറിയിപ്പ്: Backup ഫയലിൽ അംഗങ്ങളുടെ സ്വകാര്യ വിവരങ്ങളും പഴയ അഡ്മിൻ പരിശോധനാ മൂല്യവും ഉണ്ടായേക്കാം. ഈ ഫയൽ ആരുമായും പങ്കിടരുത്; WhatsApp-ലോ പൊതുവായ Drive ഫോൾഡറിലോ അപ്‌ലോഡ് ചെയ്യരുത്.
തയ്യാറാണ്. ബട്ടൺ അമർത്തുക.

ഈ പേജ് വായന (read) മാത്രം നടത്തുന്നു. Firebase Rules മാറ്റില്ല.
